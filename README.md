# Molin Shopping List

A family shopping list that works on any phone.

## Features
- Add an item with **brand**, **quantity** and **store**: Costco, ShopRite, Food Universe, Stop & Shop, Amazon or Other
- **"I'll pick it up"** lets a family member confirm they're getting an item, so nobody doubles up
- **Automatic price estimates** based on the item, brand and store (you can always type your own price)
- **Estimated total** for the whole list and a subtotal for each store
- Tick items off as bought, then clear them in one tap

## Running it
- **Shared (recommended):** open the published Claude artifact link and share it with family members as Contributors. Everyone sees the same list, live.
- **Standalone:** open `index.html` in a browser (or host it on GitHub Pages). In this mode the list is saved on that device only.
